# Memory index

- [No feature branches — work on main](feedback_no_feature_branches_work_on_main.md) — never create feature/working branches; commit and push directly to main. Overrides the default "branch first on the default branch" guidance.
- [Always push after commit](feedback_always_push_after_commit.md) — standing instruction: every commit gets pushed without asking, overriding the default guardrail.
- [Commit .claude/ changes routinely](feedback_commit_claude_dir_routinely.md) — .claude/{settings.json, settings.local.json, memory/*} are regular tracked content. Stop treating their modifications as session-drift to defer.
- [Skip redundant final review in subagent-driven-development](feedback_skip_redundant_final_review.md) — after per-task two-stage reviews pass, go straight to finishing-a-development-branch; do not dispatch a final cross-cutting reviewer. Also skip the per-task code-quality (2nd) stage for doc-only tasks (spec review suffices); keep both stages for code/logic/templates.
- [Check Windows chezmoi before apply](feedback_windows_chezmoi_check_before_apply.md) — when a sync must reach Windows, verify chezmoi.exe exists first; if present apply via interop, else deploy manually (never substitute the WSL Linux chezmoi — it renders templates as os=linux and re-breaks the ssh fix).
- [WSL appendWindowsPath=false for fast chezmoi/czt](project_wsl_appendwindowspath_false.md) — on WSL, LookPath-heavy tools (chezmoi → czt) stall ~1.6s because ~90 /mnt/c PATH dirs get stat-walked over drvfs; fix = appendWindowsPath=false in /etc/wsl.conf (+wsl --shutdown) plus the rc re-add of just PowerShell+system32. Check this before theorizing about chezmoi/cz* slowness.
