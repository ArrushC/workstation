In brainstorming and design loops, self-review every section before asking for approval. Only stop to consult when input is genuinely required — taste decisions, scope changes, or ambiguities I cannot resolve from context.

**Why:** The user said "please do self review and consult with me only when it genuinely requires my input." Per-section approval gates in `superpowers:brainstorming` are well-intentioned but, for this user, become friction noise when the section is a straightforward elaboration of an already-approved direction.

**How to apply:** When working through a multi-section design where the spine is settled, batch sections together rather than asking after each. Keep the spec-review gate (the deliberate handoff point before writing-plans) — that one is the user's redirect window and is worth preserving. Same for sections where I genuinely cannot pick between options without taste input (mechanism / scope / rollout-shape style choices) — those still warrant AskUserQuestion.
