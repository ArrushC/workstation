# Simplification PR 2 — Tasks on mise — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace hand-rolled task plumbing with mise features, and drop the commands that duplicate mise built-ins:
- the one-line wrapper tasks become TOML tasks
- owned-only work is gated by where its bootstrap hook is declared, not `env_has`
- `REBUILD=1` becomes a declared flag
- the pre-commit hook is generated by mise
- `bootstrap.sh --doctor/--check-for-updates` and `inventory` go

**Architecture:**
- Repo-maintenance wrappers move into `[tasks]` in `config.toml`. The owned-Linux-only wrappers (`statusline`, `enable-el-repos`) move into `config.host.toml`. Logic-bearing tasks stay as files in `tasks/`.
- Owned-only steps run from `final` hooks declared in `config.host.toml` (vcpkg, a new `claude` task) and `config.native.toml` (fonts). `final` runs only on a full `mise bootstrap`: not `--only dotfiles` (`wsa`), and not on shared hosts, which never load those files.
- `check-updates` shrinks to `mise outdated` + dnf + three `git ls-remote` lines.

**Deviation from the spec (recorded):** spec §5 PR 2 item 3 says to derive the repo root from `MISE_TASK_DIR`. This plan keeps each file task's one-line `root=` (readlink of `$0`) instead. The tests in Tasks 3 and 4 invoke task files directly, where `MISE_TASK_DIR` is unset, and the unused boilerplate goes anyway (Task 4).

**Tech Stack:** mise 2026.9.9 (TOML tasks, `#USAGE` specs, bootstrap hooks, `mise generate git-pre-commit`), bash, TOML.

**Spec:** `docs/superpowers/specs/2026-09-29-simplify-design.md` §5 PR 2 (and §3 for the verified mise facts).

## Review Focus

1. **A shared host, or `wsa`, runs an owned-only step** (vcpkg, Claude Code, fonts). A shared host never loads `config.host.toml`/`config.native.toml`, and `wsa` never runs `final`. Task 3, step 1 pins this with a dry-run matrix across every token set and `--only` form.
2. **The interactive statusline prompt loses its terminal** now that it's a TOML task. Task 3, step 5 checks `raw = true` and that `bootstrap.sh` still calls it only on an owned host with a TTY.
3. **The pre-commit check silently stops running** on an existing clone whose `core.hooksPath` still points at the deleted `.githooks/`. Task 2, step 4 proves `install-hooks` clears it and that a commit runs the check.
4. **`mise run fmt` formats a different file set than lint checks.** Task 1, step 4 proves `fmt` makes no diff and uses exactly lint's list.
5. **Someone types a removed command** (`./bootstrap.sh --doctor`, `REBUILD=1 mise run python-env`) and gets a silent no-op. Task 5, step 4 and Task 4, step 3 pin a clear error or the documented replacement.

- [ ] **Step 1: Write the gating test first (it fails now)**

Save as `/tmp/claude-pr2-gating.sh`:
```bash
#!/usr/bin/env bash
# Owned-only steps must run only on owned Linux hosts, and only on a full bootstrap.
set -uo pipefail
cd /tmp
fail=0
hooks() { MISE_ENV="$1" timeout 180 mise -C "$HOME" bootstrap $2 --dry-run --yes </dev/null 2>&1 | grep -E "^sh -o errexit -c 'mise run" ; }
for e in linux,owned,host,wsl linux,owned,host,native; do
  out=$(hooks "$e" "")
  grep -q "mise run vcpkg ::: claude" <<<"$out" || { echo "FAIL $e full: no vcpkg/claude final hook"; fail=1; }
  case "$e" in *native*) grep -q "mise run fonts" <<<"$out" || { echo "FAIL $e full: no fonts hook"; fail=1; } ;;
               *) grep -q "mise run fonts" <<<"$out" && { echo "FAIL $e full: fonts hook on WSL"; fail=1; } ;; esac
  out=$(hooks "$e" "--only dotfiles")
  grep -qE "vcpkg|claude|fonts" <<<"$out" && { echo "FAIL $e --only dotfiles runs owned steps"; fail=1; }
done
out=$(hooks linux "")
grep -qE "vcpkg|claude|fonts|statusline" <<<"$out" && { echo "FAIL shared host runs owned steps"; fail=1; }
MISE_ENV=linux mise -C "$HOME" tasks ls 2>/dev/null | grep -qE '^(statusline|enable-el-repos)\b' && { echo "FAIL shared host sees owned-only tasks"; fail=1; }
MISE_ENV=linux,owned,host,wsl mise -C "$HOME" tasks ls --hidden 2>/dev/null | grep -q '^enable-el-repos' || { echo "FAIL owned host lacks enable-el-repos"; fail=1; }
[ $fail -eq 0 ] && echo "gating: PASS"
exit $fail
```

```bash
#!/usr/bin/env bash
#MISE description="Report available updates: mise tool pins, dnf (owned Linux hosts), and the config.toml [vars] pins vs upstream tags"
#MISE env={PYTHON_VERSION="{{ vars.python_version }}", NERD_FONT_VERSION="{{ vars.nerd_font_version }}", VCPKG_VERSION="{{ vars.vcpkg_version }}"}
set -uo pipefail

printf '==> mise tools\n'
mise outdated --bump || true

case ",${MISE_ENV:-}," in
*,host,*)
  printf '\n==> dnf\n'
  dnf -q check-update | head -40 || true # exit 100 means updates exist; never fail
  ;;
esac

# report <name> <pinned> <github owner/repo> <tag prefix>: the newest clean
# numeric tag upstream vs the pin (git ls-remote: no API, no rate limit).
report() {
  local latest
  latest=$(GIT_TERMINAL_PROMPT=0 timeout 30 git ls-remote --tags --refs "https://github.com/$3.git" "refs/tags/$4*" 2>/dev/null |
    sed "s#.*refs/tags/$4##" | grep -E '^[0-9]+(\.[0-9]+)*$' | sort -V | tail -1)
  if [ -z "$latest" ]; then
    printf '  ? %-12s %s (no tags found; offline?)\n' "$1" "$2"
  elif [ "$latest" = "$2" ]; then
    printf '  ✓ %-12s %s\n' "$1" "$2"
  else
    printf '  ↑ %-12s %s → %s\n' "$1" "$2" "$latest"
  fi
}
printf '\n==> config.toml [vars] pins\n'
report nerd-fonts "$NERD_FONT_VERSION" ryanoasis/nerd-fonts v
report vcpkg "$VCPKG_VERSION" microsoft/vcpkg ""
report python "$PYTHON_VERSION" python/cpython v
```
